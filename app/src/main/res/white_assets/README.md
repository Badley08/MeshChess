# Chess 2D White Asset Pack v2

Pack de pièces blanches 2D originales, dans un style classique d’interface d’échecs en ligne : silhouettes lisibles, contours foncés, remplissage ivoire et ombrage léger.

Chaque pièce est livrée en PNG RGBA sur une toile de 1024×1024 px, avec transparence réelle et alignement bas pour une intégration directe dans un jeu.

Fichiers : `board.png`, `pawn.png`, `bishop.png`, `rook.png`, `knight.png`, `queen.png`, `king.png`.
